MODEL ARCHITECTURE

From pixels to prediction.

Exact machine learning pipeline implemented in the training notebook, utilizing transfer learning with EfficientNetV2B0 fine-tuned on CIFAR-100.

01 · INPUT

Input Matrix

Raw image converted to RGB 3-channel matrix and resized to 96 × 96 spatial resolution.

Shape: (96, 96, 3)
02 · AUGMENTATION

Data Augmentation

Keras augmentation layers: RandomFlip, RandomRotation(0.15), RandomZoom(0.15), RandomTranslation(0.1, 0.1), and RandomContrast(0.1).

tf.keras.Sequential
03 · BACKBONE

EfficientNetV2B0

Pretrained ImageNet feature extractor utilizing Fused-MBConv and compound coefficient scaling.

Output: (3, 3, 1280)
04 · POOLING

GlobalAveragePooling2D

Spatial pooling across H×W dimensions, reducing 3D feature maps into a fixed-length feature vector.

Vector: 1280-d
05 · NORMALIZATION

BatchNormalization

Normalizes mini-batch activations to zero mean and unit variance, stabilizing internal covariate shift.

Layer: BatchNorm
06 · PROJECTION

Dense(512, ReLU)

Fully connected projection layer with Rectified Linear Unit activation for high-level semantic representation.

Units: 512 ReLU
07 · REGULARIZATION

Dropout(0.4)

Randomly zeros 40% of activations during training to break co-adaptation and prevent overfitting on 100 classes.

Rate: 0.40
08 · SOFTMAX

Dense(100, Softmax)

Final output layer producing normalized probability distribution summing to 1.0 across all 100 CIFAR categories.

Output: 100 Softmax
TRAINING & OPTIMIZATION REGIME

Two-Stage Transfer Learning

Phase 1 · Feature Extraction

Base EfficientNetV2B0 weights are frozen (base_model.trainable = False). Only the custom classification head is trained using Adam with learning rate 1e-3.

Phase 2 · Fine-Tuning

Base model layers are unfrozen (base_model.trainable = True). Entire network is trained end-to-end with low learning rate 1e-5 and ReduceLROnPlateau to preserve pretrained weights.

RESEARCH & FOUNDATIONAL THEORY

Understanding the Vision Architecture

An engineering and academic breakdown of CIFAR-100 classification, Convolutional Neural Networks, Transfer Learning, and inference mechanics.

BENCHMARK DATASET

What is CIFAR-100?

The CIFAR-100 dataset is an established computer vision benchmark consisting of 60,000 32×32 color images across 100 fine-grained classes (600 images per class: 500 training, 100 test). Unlike CIFAR-10's 10 classes, CIFAR-100 presents substantial inter-class similarity and low sample count per category, making it an ideal testbed for transfer learning and regularization.

NEURAL TOPOLOGY

What is a CNN & Why It Works

Convolutional Neural Networks (CNNs) process grid-structured pixel arrays using learnable filter kernels. CNNs exploit translation equivariance and local spatial correlation. Early layers capture low-level edges and textures, intermediate layers detect object parts and shapes, and deep layers formulate high-level semantic abstractions.

BACKBONE SELECTION

Why EfficientNetV2B0?

EfficientNetV2 improves upon standard ConvNets by using Neural Architecture Search (NAS) and compound scaling to optimize accuracy, parameter count, and training latency simultaneously. It introduces Fused-MBConv layers in early stages, accelerating training throughput and delivering state-of-the-art representation with only ~7.1M parameters.

LEARNING PARADIGM

Transfer Learning Mechanics

Instead of training from random Gaussian initialization, transfer learning initializes the backbone with weights pre-trained on ImageNet (1.4M images, 1000 classes). We employ a two-stage strategy: first freezing the backbone to train our Dense(512) classification head, then fine-tuning the full network with a tiny learning rate (1e-5) to adapt features to CIFAR-100.

RUNTIME PIPELINE

How the Backend Performs Inference

When an image is submitted from the browser, the following end-to-end execution path takes place:

Step 1
Multipart Upload
Browser streams raw image bytes via HTTP POST to FastAPI /predict.
Step 2
Preprocessing
Pillow decodes bytes to RGB, bilinear-resizes to 96×96, and creates a (1, 96, 96, 3) float32 tensor.
Step 3
Keras Forward Pass
TensorFlow executes inference across best_model.keras producing 100-way logits.
Step 4
Softmax & Ranking
Softmax probabilities are sorted to extract Top-1 and Top-5 class names with percentage confidence.
