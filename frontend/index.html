TECHNICAL PIPELINE

From pixels to prediction.

A 4-stage transfer learning pipeline transforming raw pixel matrices into probabilistic class distributions.

STAGE 01

Input Matrix

Receive an RGB image and resize to 96 × 96 spatial resolution with 3 color channels.

Shape: (1, 96, 96, 3)
STAGE 02

Augmentation

Random horizontal flip, rotation (15%), zoom (15%), and contrast adjustments during training.

Layer: tf.keras.Sequential
STAGE 03

Feature Extraction

Pretrained EfficientNetV2B0 extracts hierarchical multi-scale visual representations.

Backbone: EfficientNetV2B0
STAGE 04

Classification Head

GlobalAveragePooling2D followed by Dense(512) and Dense(100, softmax) classification.

Dense(100, softmax)
FOUNDATIONAL THEORY

Why use Transfer Learning with EfficientNet?

EfficientNet uses compound coefficient scaling to uniformly scale depth, width, and resolution, capturing intricate visual patterns far beyond basic small-kernel ConvNets.

Pretrained Weights

Leverages ImageNet representations to accelerate convergence on fine-grained categories.

Two-Stage Fine-Tuning

Initial training freezes the base model (lr=1e-3); fine-tuning unfreezes layers with low lr (1e-5).

Regularization

BatchNormalization, Dropout(0.4), and ReduceLROnPlateau prevent catastrophic overfitting.
