From pixels to probabilistic prediction.

A multi-stage feedforward tensor architecture designed specifically for low-resolution 32×32 spatial matrix feature extraction and 100-way categorical classification.

TECHNICAL PIPELINE

End-to-end feedforward stages.

How raw RGB matrices are progressively abstracted into invariant semantic representations.

STAGE 01

Input Matrix

Receive a 32 × 32 RGB image and normalize pixel channels from uint8 integers [0-255] to float32 scales [0.0-1.0].

Shape: (1, 32, 32, 3)
STAGE 02

Convolution

Extract edges, textures, shapes and localized patterns using spatial 3×3 receptive field kernels with ReLU activations.

Filter: Conv2D(32, 3×3)
STAGE 03

Feature Pooling

Compress activations to build increasingly compact hierarchical representations while maintaining spatial invariance.

Downsample: MaxPool2D(2×2)
STAGE 04

Classification

Flattened dense layers compute softmax probabilities across all 100 fine categories, producing likelihood distributions.

Dense(100, softmax)

FOUNDATIONAL THEORY

Why use a Convolutional Neural Network?

Unlike standard feedforward multi-layer perceptrons that treat pixel arrays as flat 1D vectors, CNNs preserve 2D topological geometry through localized receptive fields and shared weight matrices.

Local Receptive Fields

Filters process nearby pixel neighborhoods directly, identifying local edges, gradients, and textures without spatial flattening.

Weight Sharing

The identical filter weights scan across the entire grid, granting translation invariance and lowering parameter counts.

Hierarchical Features

Early layers capture primitive contours; intermediate layers compose textures; deeper layers resolve semantic classes.
