# CIFAR-100 CNN Model Training Notebooks

This directory contains the machine learning experimentation and training notebooks for the CIFAR-100 Image Classifier.

## Overview

- **Dataset**: CIFAR-100 (100 fine classes, 20 coarse superclasses)
- **Model Architecture**: Deep CNN / Transfer Learning (EfficientNetV2B0) with Data Augmentation
- **Output Target**: `cifar100_model.keras` (exported to `backend/model/`)
